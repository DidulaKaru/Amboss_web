# Amboss Backend API Server (`server/`)

This directory houses the Fastify REST API, PostgreSQL database layer (Drizzle ORM), authentication system, and business logic for the Amboss platform.

---

## What This Section Does

1. **Deterministic 3D Print Quoting:**
   - Evaluates part geometries, material costs, machine runtimes, and preparation QA fees.
   - Enforces the **250 LKR** minimum order policy.
2. **Maker Store Inventory API:**
   - Serves maker hardware catalog with categories and real-time stock levels.
   - Provides live cart stock validation before WhatsApp order redirection.
3. **Dynamic Portfolio Gallery API:**
   - Serves active case studies and 3D print projects.
   - Protected endpoints for adding, updating, and removing portfolio records.
4. **Single-Owner Admin Authentication & CMS:**
   - Environment-driven bcrypt verification (`ADMIN_PASSWORD_HASH`).
   - Issues 24-hour JWT tokens stored in HttpOnly cookies (`amboss_admin_token`) and Bearer headers.
   - Restricts catalog mutations (`POST`, `PUT`, `DELETE /api/v1/products` and `/api/v1/portfolio`) with `verifyAdmin` middleware.
5. **Logistics & WhatsApp Payload Generation:**
   - Formats customer orders with transparent itemization and delivery calculations.

## Directory Structure

```
server/
├── src/
│   ├── config/              # Environment parser (env.ts) and logistics SSOT (logistics.ts)
│   ├── db/                  # Drizzle ORM schema, PostgreSQL connection, seed data
│   ├── middleware/          # Authentication guards (verifyAdmin via @fastify/jwt)
│   ├── routes/              # Fastify route plugins (health, materials, products, quote, orders, portfolio, admin)
│   ├── services/            # Pure business logic (pricingService.ts, logistics.ts)
│   ├── app.ts               # Fastify app builder, empty JSON body parser, & plugin registration
│   └── index.ts             # Entry point listening on port 4000
├── drizzle/                 # Versioned SQL migration files generated by Drizzle Kit
├── tests/                   # Vitest API integration test suites using Fastify .inject()
├── Dockerfile               # Production multi-stage Alpine container build
├── .dockerignore            # Docker build ignore rules
├── drizzle.config.ts        # Drizzle ORM migration configuration
├── .env.example             # Documented environment variable template
├── tsconfig.json            # Node.js TypeScript compilation configuration
└── package.json             # Server dependencies and scripts
```

## Environment Configuration

Copy `server/.env.example` to `server/.env` to configure settings:

| Variable | Default | Purpose |
| :--- | :--- | :--- |
| `PORT` | `4000` | Port for the Fastify HTTP server |
| `HOST` | `0.0.0.0` | Network binding interface (required for container deployments) |
| `NODE_ENV` | `development` | Runtime environment (`development`, `production`, `test`) |
| `CORS_ORIGIN` | `http://localhost:5173` | Allowed CORS origins (comma-separated in production) |
| `DATABASE_URL` | `postgresql://...` | PostgreSQL pooled connection string (Neon pooled URL with `?sslmode=require`) |
| `DATABASE_URL_DIRECT` | `postgresql://...` | Unpooled direct connection string for running migrations & seeds |
| `JWT_SECRET` | `amboss-industrial-...` | Secret used to sign admin session tokens |
| `ADMIN_USERNAME`| `Dory` | Single-owner admin username |
| `ADMIN_PASSWORD_HASH` | `$2b$10$...` | Bcrypt hash for admin password |

## Database Management (Neon / PostgreSQL)

```bash
# Generate SQL migration from schema.ts
npm run db:generate

# Execute migration against PostgreSQL / Neon database
npm run db:migrate

# Seed database with initial materials, machines, products, and portfolio items
npm run db:seed
```

## Container Build (Koyeb / Fly.io / Docker)

```bash
# Build production Docker container
docker build -t amboss-server .

# Run container locally
docker run -p 4000:4000 --env-file .env amboss-server
```

## Local Development & Testing

```bash
# Start server in watch mode (using tsx)
npm run dev --workspace=server

# Run all backend Vitest integration tests (21 tests)
npm test --workspace=server

# Compile production TypeScript bundle
npm run build --workspace=server
```
